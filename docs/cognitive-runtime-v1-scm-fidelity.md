# Cognitive Runtime V1 SCM Fidelity

SCM treats Nemosine Nous as human-in-the-loop, assisted by LLM linguistic engines, organized through symbolic functional roles and semantic topologies, externally controlled and non-autonomous.

V1 therefore implements an external control, validation and governance layer around constrained linguistic generation.

## Interpretive Guardrails

- The human user remains the locus of goal-setting, symbolic role selection, final judgment, responsibility and authorization.
- The selected visible persona remains the user-invoked symbolic role.
- Scientist and Philosopher are controlled evaluation roles applied by the runtime, not autonomous personas.
- Runtime profile selection is a technical safety policy, not symbolic reconfiguration.
- Runtime states are processing states, not mental or conscious states.

Preferred wording:

> The runtime applied the veritative criteria associated with the Scientist and the ethical-epistemological criteria associated with the Philosopher.

Avoid wording that says the Scientist or Philosopher independently decided, acted, formed goals or changed the symbolic topology.

## Symbolic Configuration Versus Runtime State

Symbolic configuration includes persona, place, symbolic framing and interaction perspective selected by the user. Runtime state includes processing stage, validation status, retry status, promotion status and persistence status.

Automatic profile elevation may move from `standard` to `full` for high-stakes validation. It must not change the active persona, activate another visible persona, alter the active place, invent objectives or change user intent.

## Double Vigilance

The veritative axis evaluates logic, factual support relative to available evidence, contradiction, unsupported claims, simulated access and uncertainty honesty.

The ethical-epistemological axis evaluates constitutional conformity, user sovereignty, non-idolatry, ethical legitimacy, epistemological humility, dependency/manipulation risk and vocation integrity.

Both axes are operationally separated modules. Neither is a claim of autonomous cognition.

## Implemented Versus Conceptual

Implemented in V1: buffered candidate generation, structured extraction, deterministic hard checks, LLM validators in standard/full profiles, Vigia coherence, promotion gate, authorized side-effect committer and redacted audit.

Conceptual or incomplete: external factual verification, empirical validation of theta, complete patent embodiment coverage, full persona-quality validation and user-facing consent controls.
