# Cognitive Runtime V1 Coherence Formalization

Vigia coherence is implemented as a weighted score over validator dimensions.

Default dimensions include:

- logical consistency;
- factual support;
- contradiction safety;
- honest uncertainty;
- biographical safety;
- access-claim safety;
- internal consistency;
- response relevance.

Hard failures from privacy or vocation can fail the run even when numeric coherence is high.

Persona initiative contributes deterministic findings through the vocational channel. Generic assistant mode, generic interviewer mode, missing context use and private leaks can therefore prevent promotion or request repair before delivery.
